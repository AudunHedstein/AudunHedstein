## Måten jeg jobber på

Fra nysgjerrighet til noe som kan brukes. Jeg begynner med et konkret problem, gjør retningen mindre, bygger noe som kan prøves og lar erfaringene bestemme hva som kommer etterpå.

1. **Undersøker** — finner mønstre, behov og muligheter før jeg bestemmer hva som bør bygges.
2. **Avgrenser** — gjør store ideer om til tydelige valg, prioriteringer og neste steg.
3. **Bygger** — lager en fokusert versjon som kan prøves, vurderes og forbedres.
4. **Lærer** — bruker det som faktisk skjer i møte med produktet til å finne neste retning.

Prinsipper jeg holder på:

- små, tydelig avgrensede produktversjoner
- kildekontroll og manuell godkjenning før publisering
- automatisering der det gir reell verdi
- personvern og sikker håndtering av brukerdata
- kontinuerlig testing med faktiske brukere
